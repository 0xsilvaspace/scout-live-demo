    Recommended order for Scout on Pi 5 (8 GB — enough):
    • Start local (now, v4): short-term turns in RAM fix the repeat-answer bug; long-term facts in local JSON survive restarts, work offline, cost nothing.
    • Add Chroma locally if you want meaning-based recall (“things I like to eat” finding “jollof”) without any cloud.
    • Add Pinecone only for cloud sync across devices or very large memory. Its free Starter is about 2 GB, then roughly $70/month — not worth it while local memory covers the need.
    • How Pinecone would work: each memory is embedded into numbers, stored in Pinecone, and the 3–5 closest memories are pulled into the prompt before each reply.

    In short: local memory gives Scout a past today. Pinecone is the upgrade path, not the starting point.

    Scout's Live system prompt — the English-only rule (v4.1)

    This is the exact rule that goes at the top of the system prompt for the Gemini Live session on the Pi, with speech language set to en-NG. Why both? Google's own docs say Live can switch among 97 languages mid-conversation and language_code mainly sets the accent — so the prompt rule does the locking, and the demo's language guard (below in the chat) catches anything that still slips through.

    Language guard, live in this demo: every Scout reply is checked before it is shown or spoken. If it contains a non-Latin script (for example Hindi, Arabic, Chinese or Cyrillic letters) or clear non-English words, you will see a warning and Scout automatically repeats the reply in English. Try it: type something in Spanish or paste a Hindi sentence — Scout answers in English and asks you to repeat it in English.
